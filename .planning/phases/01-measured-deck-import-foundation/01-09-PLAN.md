# Plan 01-09 — Pin the Archidekt contract with fixture tests

<objective>
Plan 01-08 wrote the normalizer. This plan makes it trustworthy. Archidekt's endpoint is the
undocumented, unversioned internal SPA API — it can change without notice, and the failure mode
that matters is not a crash but a *silent* mis-parse that hands a player the wrong deck. Pin the
field mapping to the committed live capture so a shape change breaks a test instead of a user's
import.

Tests only. If a test reveals a defect in 01-08's normalizer, fix the normalizer — do not weaken
the assertion to match the bug.
</objective>

<context>

## The capture

`server/testdata/deck_providers/archidekt_deck_2026-08-05.json` — real live response for deck
13074677, captured 2026-08-05. 113 card rows, 126 total quantity, 15 deck-level categories.

Ground-truth values to assert against, all confirmed present in that file:

| Assertion | Expected |
|---|---|
| in-deck quantity (excluding `includedInDeck:false` categories) | **100** |
| excluded (`Maybeboard`-tagged) quantity | **26** |
| card rows | 113 |
| commander cards | exactly 1 — `Cid, Timeless Artificer` |
| a sample set code | `cards[i].card.edition.editioncode` is lowercase, e.g. `"kld"` |
| a sample collector number | `cards[i].card.collectorNumber` is a string, e.g. `"34"` |
| deck-level `Maybeboard` | `includedInDeck: false` — the only such entry |
| deck-level `Commander` | `isPremier: true`, `includedInDeck: true` |

100 + 26 = 126 is the arithmetic that makes the exclusion rule falsifiable. A regression that
starts counting maybeboard rows produces 126 and fails loudly. That single assertion is the most
valuable line in this plan.

Note the comma in `Cid, Timeless Artificer`. Plan 01-02 fixed a comma-truncation bug where
`1,Atraxa, Praetors' Voice` truncated to `Atraxa`; the provider path must not reintroduce it.

## Existing patterns to reuse — do not invent new ones

`server/deck_providers_test.go` already establishes the hermetic pattern from plan 01-07 and
code-review fix `cd5ae3f`:

- `withDeckProviderFetchSpy(t)` (around line 455) swaps the `deckProviderFetch` seam and returns
  a call counter, restoring it via `t.Cleanup`. `TestProvider_KillSwitch` and
  `TestProvider_KillSwitchRequiresAllowlist` assert `*called == 0` — proving **zero dial
  attempts**, not merely that an error was returned. Reuse this; it is stronger than asserting
  on an error string.
- `TestSafeClient_InitialRequestHostEnforced` (around line 239) shows allowlist enforcement
  tested without a live host.

`server/test.go`'s `testAPI(t)` reads `DATABASE_URL` with the local DSN as a documented fallback,
sets generous rate-limit budgets, and closes its pool in `t.Cleanup` (code-review fixes `c22e8c5`
and `115c24e`). Postgres has `max_connections=100` and a full package run is close enough to that
ceiling that plan 01-05 had to fix an exhaustion failure — so prefer table-driven subtests over
many separate `testAPI(t)` call sites. If you hit `pq: sorry, too many clients already`, fix the
pooling, never by deleting coverage.

Load the committed fixture from disk (never an inline literal — the point is to test the *real*
capture, and a copy would drift). Feed it through `archidektAdapter.normalizeToDeckText`, then
through `deckimport.Parse`, and assert:

1. **Quantity accounting** — in-deck total is exactly **100**; the maybeboard rows contribute
   **26** and are dropped by the grammar with a counted summary warning, not silently. Assert the
   warning exists and names the count.
2. **`AssertAccounting` holds** on the parsed result — no nonblank emitted row disappears without
   becoming an entry, warning, blocking error, or counted drop.
3. **Commander preselection** — exactly one candidate, named `Cid, Timeless Artificer`, in
   `SectionCommander`. Assert the full name including the comma, as one string.
4. **Printing metadata** — for at least one row, the parsed entry carries the set code and
   collector number from `edition.editioncode` / `collectorNumber`, with set-code case preserved
   exactly as the response wrote it.
5. **Source** — `adapter.source()` is `deckimport.SourceArchidekt`, and the parsed deck's
   `Source` reflects it.
6. **Malformed-input fail-closed** — empty body, non-JSON bytes, valid JSON with no `cards[]`,
   and a card row missing `card.oracleCard.name` each return an error rather than a partial deck.
   Assert the returned error text contains **no** bytes from the input (see 01-08's error-hygiene
   requirement and the comment at `deck_import.go:267`); a table-driven subtest is the right shape.

Name these `TestArchidekt_*` so a `-run 'TestArchidekt_'` gate actually selects them. Plan 01-06
shipped a verification gate whose regex matched zero tests; a gate that selects nothing is worse
than no gate because it reports success.

Assert the end-to-end URL path through the kill switch, with the fetch seam stubbed to return the
captured fixture and **zero real dials**:

1. With the provider enabled and `archidekt.com` allowlisted, `previewDeck` given a
   `SourceURL` returns a `DeckPreview` whose `CardCount` matches the same-100 total, with
   `CanContinue` true.
2. The preview's card count equals the created library's length for the same parsed value — the
   same invariant `TestDeckImport_SingleParse` proves for the paste path. The provider path must
   reuse it, not fork a second parse.
3. With the provider **disabled** (default), the same URL yields a blocking error telling the
   user to paste text instead, `CanContinue` false, and the fetch spy records **zero calls**.
4. A non-allowlisted host is rejected without a dial, even with the flag on.
