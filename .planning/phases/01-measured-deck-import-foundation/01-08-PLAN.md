## The observed contract

Committed capture: `server/testdata/deck_providers/archidekt_deck_2026-08-05.json` (568 KB on
disk, deck id 13074677, 113 card rows, 126 total quantity).

Field paths confirmed present in that file:

| Value | Path |
|---|---|
| card rows | `cards[]` |
| quantity | `cards[i].quantity` (number) |
| card categories | `cards[i].categories` (array of strings, e.g. `["Maybeboard","Oomph"]`) |
| card name | `cards[i].card.oracleCard.name` |
| set code | `cards[i].card.edition.editioncode` (lowercase, e.g. `"kld"`) |
| collector number | `cards[i].card.collectorNumber` (string, e.g. `"34"`) |
| deck-level categories | `categories[]` with `{name, isPremier, includedInDeck, includedInPrice}` |

**The load-bearing rule.** Deck-level `categories[]` is the authority on whether a category's
cards count toward the deck. In the capture, exactly one entry has `includedInDeck: false`:
`{"name":"Maybeboard","isPremier":false,"includedInDeck":false,...}`. Summing quantities:

- excluding `Maybeboard`-tagged rows → **100** (a legal Commander deck)
- including them → **126** (wrong)

A card carries *multiple* categories simultaneously (`["Maybeboard","Oomph"]`), so the test is
"does any of this card's categories name a deck-level category with `includedInDeck: false`",
not "is its first category Maybeboard".

The `Commander` deck-level category has `isPremier: true`, `includedInDeck: true`, and exactly
one card carries it: `Cid, Timeless Artificer` — note the comma in that name.

## Grammar you are emitting into

`pkg/deckimport` already handles everything the normalizer needs, from plan 01-02:

- Section headers via `sections.go` (`matchSectionHeader`, `sectionTracker`): a `Commander`

- `SourceArchidekt` already exists in `sourcetype.go` — the enum is closed at four values, so

Emitting **text with section headers** rather than hand-building `ParsedEntry` values is the
point: it reuses the whole proven grammar and keeps a single canonical parse.

**Remove** (user decision, recorded in `G-01-1`): `moxfieldAdapter`, its `source()` and
`normalizeToDeckText`, the `errMoxfieldContractUnverified` sentinel, the `moxfieldHost`
constant, and the registry entry. Leave `deckProviderAdapters` registering only providers with
an observed contract. Re-addable later if authorized Moxfield access is obtained.

**Add** `archidektAdapter`:

- `source()` returns `deckimport.SourceArchidekt`.
- `normalizeToDeckText(body []byte) (string, error)` decodes the response and emits canonical
  decklist text:
  1. Build the excluded-category set: deck-level `categories[]` entries with
     `includedInDeck == false`.
  2. Identify the commander category: a deck-level entry named `Commander` (treat `isPremier`
     as corroborating, not required).
  3. Bucket each `cards[i]` — excluded if **any** of its `categories` is in the excluded set;
     otherwise commander if its categories include the commander category; otherwise main.
  4. Emit main rows first, then a `Commander` header and its rows, then a `Maybeboard` header
     and the excluded rows. The grammar drops the maybeboard rows with one counted warning,
     which is what keeps the accounting invariant true rather than silently discarding 26 rows.
  5. Per row: `quantity` then `card.oracleCard.name`, plus D-07 printing metadata from
     `card.edition.editioncode` and `card.collectorNumber` when both are present. Names go out
     plainly — unquoted commas are already a supported syntax.

Register it under the `archidekt.com` hostname.

**Error hygiene.** `previewDeckURL` logs `normalizeToDeckText`'s error, and the comment at
`deck_import.go:267` states that no adapter's error carries provider response content. Return
static sentinels (malformed JSON, no card rows, missing name field) — never wrap raw response
bytes, a card name, or a deck name into the error. If you cannot preserve that invariant,
update the comment in the same commit rather than leaving it false.

Do not touch `fetchDeckProviderURL`, `safeControl`, the redirect check, the timeouts, the body
cap, or `providerEnabled`. Do not change the `withAuthContext` / `withMetricsAuth` ordering in
`server/graphql.go` — that is a known pre-existing `/prometheus` 401 the user chose not to fix
in Phase 1.
